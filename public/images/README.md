Place custom portfolio images in this folder.

- Profile image: `public/images/profile-photo.jpg`
- Project previews: any image path referenced from `lib/data.js`, for example `public/images/tournahub-preview.jpg`

Recommended sizes:

- Profile image: square, at least `800x800`
- Project preview: `1600x900` or similar 16:9 image

Use optimized `.jpg`, `.png`, or `.webp` files for best performance.
